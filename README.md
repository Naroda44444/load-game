# 🎮 Простий лаунчер ігор для навчання

Це простий графічний лаунчер ігор, створений на **Python + Tkinter**.
Проєкт підходить для навчання основ GUI, роботи з файлами, JSON та запуску зовнішніх програм.

---

## 📌 Можливості

* ➕ Додавання ігор ( `.exe` файлів )
* ▶ Запуск вибраної гри
* 🗑 Видалення ігор зі списку
* 💾 Автоматичне збереження списку ігор у файл `games_simple.json`
* 📜 Зручний список ігор з прокруткою

---

## 🖥 Вимоги

* **Python 3.8+**
* Операційна система: **Windows**
  (через використання `.exe` файлів)
* Додаткові бібліотеки **не потрібні** (використовуються стандартні)

---

## 📂 Структура проєкту

```
project/
│── launcher.py          # Основний файл програми
│── games_simple.json    # Файл зі збереженими іграми (створюється автоматично)
│── README.md            # Опис проєкту
```

---

## 🚀 Запуск програми

1. Клонуйте репозиторій або скопіюйте файл `launcher.py`
2. Відкрийте термінал у папці з проєктом
3. Запустіть команду:

```bash
python launcher.py
```

---

## 🕹 Як користуватись

1. Натисніть **➕ "Додати гру"**
2. Виберіть `.exe` файл гри
3. Гра з’явиться у списку
4. Оберіть гру та натисніть **▶ "Грати"**
5. Щоб видалити гру — натисніть **🗑 "Видалити"**

---

## 📘 Для чого цей проєкт

Проєкт створений для навчання:

* роботи з `tkinter`
* використання `Listbox`, `Button`, `Scrollbar`
* збереження даних у форматі **JSON**
* запуску зовнішніх програм через `subprocess`

---

## ⚠ Обмеження

* Працює лише з програмами `.exe`
* Не підтримує macOS та Linux
* Не перевіряє, чи файл гри був переміщений або видалений
